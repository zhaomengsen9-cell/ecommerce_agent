# Ecommerce Operations Knowledge

## 商品规则

- 商品上架前必须具备 SKU、名称、库存单位、默认仓库、可销售状态和有效价格。
- 商品价格调整应保留原因、调整前价格、调整后价格、执行人和生效时间。
- 不建议在缺货、负毛利或供应状态不稳定时扩大投放。

## 库存策略

- 库存低于安全库存时优先生成补货建议，不直接修改采购计划。
- 连续 7 天销量增长且库存周转天数低于 5 天时，标记为高补货优先级。
- 长尾商品库存周转天数高于 60 天时，优先考虑组合促销或清仓活动。

## 订单分析

- 订单分析至少按状态、销售额、客户、商品和时间维度拆分。
- 取消率、退货率、缺货取消和超时发货是电商运营异常的重点信号。
- 高客单价订单应避免用激进折扣策略替代服务体验优化。

## 营销规范

- 促销活动必须定义目标人群、商品范围、折扣/权益、预算、开始时间和结束时间。
- 折扣活动应检查毛利底线；低毛利商品优先使用满赠、组合购或会员权益。
- 创建真实 Campaign、修改价格、批量变更商品状态都属于高风险动作，需要人工审批。

## 售后流程

- 售后分析需区分质量问题、物流问题、尺码/规格不符和无理由退货。
- 对高频售后 SKU，应先暂停加大投放并定位供应链或详情页问题。
